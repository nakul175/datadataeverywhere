# Four package contract

Use the pinned Product 4.2, QA 1.3 and Engineering 2.1.0 distributions without replacing their catalogues, schemas or checkers. Workflow 2.0 owns stage order, routing, dispatch, handoff and reconciliation. All applicable controls are conjunctive; no package overrides another domain's safety controls.

One canonical product task, native criterion/case/run versions, team Ready/Done definitions, selected exception register and approved integration manifest govern each candidate. Select actual native records; empty starter files and synthetic examples are never product evidence.

Engineering owns connect_bundles.py/native_bridge.py and approved command wiring. Product owns typed task-criterion links and scope. QA owns case/run semantics and checker arguments. Workflow requires each decision and actual execution before transition. PM documentation quality never substitutes for QA execution or delivery approval.

Input archive manifests were checked against actual bytes. Native cross-package adapters and companion checkers have NOT been executed for a product; compatibility and adoption remain held until qualified. Do not weaken criteria to obtain a pass or reinterpret a structural checker as release permission.
