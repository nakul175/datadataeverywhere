# Gate checklist

For each listed check record: satisfied / held / justified non-applicable; current source and contract version; evidence URL; verified authority where required; timestamp; blocker and next action. A blank field is pending, not a pass. Mandatory applicable checks cannot be sampled away.

## Ready
1. Authorized scope.
2. Clear user outcome and boundaries.
3. Traceable measurable criteria.
4. Critical dependencies and authority resolved.
5. Versioned fixtures, oracles and complete NFR workload.
6. Safe runnable environment.
7. Linked owning tasks and project Ready/Done definitions.

## Done
1. Current implementation and exact source identified.
2. All declared applicable tests pass with complete workloads.
3. Required CI passes on final head.
4. Evidence published and read back.
5. Valid independent and required human approval.
6. Exact release and required live journey observed.
7. Project Done checklist and limitations reconciled.

Outcome validation remains separate unless project Done explicitly requires it. Relevant edits make dependent evidence and approval stale. Offline checklist completion is advisory and does not grant human approval. Domain/AI checks are conditional additions, not substitutes for mandatory gates.
